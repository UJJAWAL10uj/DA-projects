## Power BI Dashboard Spec (E-Commerce Churn)

This spec produces the 4 visuals you listed using the **customer-level churn dataset**.

### Data source
Use `data/processed/churn_risk_scored.csv` generated by the pipeline.

### Required fields
- `CustomerID`
- `Churn` (0/1)
- `Tenure`
- `OrderCount`
- `DaySinceLastOrder`
- `CashbackAmount`
- `SatisfactionScore`
- `Complain`
- `PreferredPaymentMode`, `PreferredLoginDevice`, `PreferedOrderCat`
- `churn_probability`
- `risk_band` (Green/Amber/Red)

### Measures (DAX)
- **Churn Rate** = `DIVIDE(SUM('data'[Churn]), COUNT('data'[CustomerID]))`
- **Retention Proxy** = `1 - [Churn Rate]`
- **Avg Tenure** = `AVERAGE('data'[Tenure])`
- **Avg Orders (last month)** = `AVERAGE('data'[OrderCount])`

### Visuals

1) **Monthly revenue trend (line chart)**
   - The dataset has no order dates/revenue. Use a *proxy* trend:
     - X-axis: `Tenure Band` (binned)
     - Values: `Avg Orders (last month)` OR `AVERAGE(CashbackAmount)`
   - Title: **"Engagement / Revenue Proxy by Tenure"**

2) **Cohort retention heatmap (matrix visual)**
   - Rows: Tenure Band (calculated column)
   - Columns: Recency Band (calculated column)
   - Values: **Retention Proxy**

3) **Churn risk customer list (table with RAG indicators)**
   - Columns: CustomerID, churn_probability, risk_band, DaySinceLastOrder, Complain, SatisfactionScore, OrderCount
   - Conditional formatting: risk_band colors

4) **Growth lever scenario comparison (bar chart)**
   - Use a small disconnected table with scenario churn rates (4.0%, 3.2%, 2.8%)
   - Measure calculates simulated 12-month revenue impact using an ARPU assumption.

### Calculated columns (Power BI)
Tenure Band:
```DAX
Tenure Band = 
SWITCH(TRUE(),
  ISBLANK('data'[Tenure]), "Unknown",
  'data'[Tenure] <= 3, "0-3",
  'data'[Tenure] <= 6, "4-6",
  'data'[Tenure] <= 12, "7-12",
  'data'[Tenure] <= 24, "13-24",
  "25+"
)
```

Recency Band:
```DAX
Recency Band = 
SWITCH(TRUE(),
  ISBLANK('data'[DaySinceLastOrder]), "Unknown",
  'data'[DaySinceLastOrder] <= 7, "0-7",
  'data'[DaySinceLastOrder] <= 15, "8-15",
  'data'[DaySinceLastOrder] <= 30, "16-30",
  "31+"
)
```
